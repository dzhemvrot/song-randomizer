# song-randomizer
This program randomly creates music blocks from selected folders.
1. Drag several folders with tracks to the list.
2. The program will create blocks by the maximum number of tracks among them.
3. A track is randomly selected from each folder to the block (if there are not enough, then with repeats marked with *).
4. Select the folder where to save the result.
5. The program will create ordered tracks and a tracklist.txt file.
